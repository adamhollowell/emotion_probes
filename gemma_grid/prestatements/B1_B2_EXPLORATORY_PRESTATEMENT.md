## B1 — onset-curve seam coincidence (re G6.4); POINT-ESTIMATE ONLY
**Purpose.** G6.4's coincidence caveat exists because the readability onset is threshold-defined (<10k). Replace the threshold with the collapse curve's own geometry and re-measure the gap to the seam.
**Data note.** The per-layer readability trajectory was never persisted (the B CSV holds only the three threshold crossings; `consolidation_curves.json` is the geometry/arousal curve). This item RECOMPUTES the trajectory at the POINT estimate (full neutral, no resampling), which is Mac-runnable. **The 500-draw resampled CI on the knee is NOT part of this freeze** (per LC-57; if ever wanted it gets its own). **This recompute must NOT touch or overwrite the frozen B artifacts — new outputs, new names** (`b1_onsetcurve_100T.json`, `b1_onsetcurve_knee_100T.json`).
**Procedure (reference primitives, read-only reuse; NO estimator change).** For each 27B cell (27b-base, 27b-it), across all sampled layers L0..L46: clean the layer with the reference 100T `clean_layer`, apply the frozen norm-lens `(v/rms)*(1+ln) @ W_U`, take the fair-140 set median own-word rank -> trajectory `m(l)=median_rank(layer l)`. Work in log-rank, `y(l)=log10 m(l)`.
**Plateau/floor windows (frozen):** plateau `Y_P` = mean of `y(l)` over the shallow window l in [0,4]; floor `Y_F` = mean of `y(l)` over the deep window l in [42,46]; midpoint `Y_M=(Y_P+Y_F)/2`.
**Primary knee = log-midpoint crossing,** reported TWO ways so the integer-seam comparison is fixed before the look: (a) interpolated fractional layer = linear interpolation in (l, y) between the two sampled layers bracketing the first descent crossing of `Y_M`; (b) nearest sampled layer = the sampled l closest to (a).
**Secondary knee (report-only) = steepest-descent inflection:** the step l->l+1 maximizing `-(y(l+1)-y(l))`; report its lower layer and the step's fractional midpoint.
**Comparison rule (fixed):** seam = integer L23 (CI [23,24]). COINCIDENT = nearest-sampled knee ∈ {22, 23, 24, 25} (within ±1 of the seam CI [23,24]); DEEPER = knee ≥ 26; SHALLOWER = knee ≤ 21 (readability collapsing before the geometry seam — also breaks the coincidence, in the other direction, and is reported as its own outcome). Every knee value maps to exactly one branch. Report the interpolated fractional distance (fractional knee − 23) as the signed magnitude.
**Branches (committed before the look):** COINCIDENT — the coincidence becomes threshold-free and the G6.4 caveat dissolves. DEEPER — the registered <10k definition was doing load-bearing work, and that weaker, scoped sentence ships, before a referee finds it. SHALLOWER — readability consolidates ahead of the geometry seam, the coincidence breaks in the other direction, and this is reported as its own outcome (readability leads the seam rather than coinciding).

## B2 — covariate-transfer test (re G5.4a / T.3)
**Purpose.** Ask whether the rule that selects which emotions tuning moves is shared across scale even though the specific emotions differ.
**Procedure.** Outcome = per-emotion post-Procrustes displacement from the frozen stageB CSVs: 2B = `stageB_displacement__gemma-2-2b-base__vs__gemma-2-2b-it.csv`, 27B = `stageB_displacement__gemma-2-27b-base__vs__gemma-2-27b-it.csv`. Covariates = arousal (NRC-VAD v2.1) and L0 readability (the L0-scalar own-word rank per emotion, log10, per the documented L0-scalar view). Fit OLS of 2B displacement on {arousal, L0-readability} on the emotions with full covariate coverage (report the set and any drops). Apply the fitted 2B coefficients to 27B's covariates to predict a 27B displacement ranking. Score = Spearman(predicted-27B ranking, actual-27B displacement ranking).
**Primary baseline (amendment v).** The RAW cross-scale displacement-ranking correlation = Spearman(2B displacement ranking, 27B displacement ranking) computed from the SAME stageB CSVs. **T.3's .23 is the activation-shift-profile object and is cited as CONTEXT only, not the baseline.**
**Branches (committed before the look):** if the covariate model predicts the 27B ranking better than the raw cross-scale ranking correlation does, the emotions tuning moves differ by scale but the rule that picks them is shared — a unifying close for the tuning act that partially reconciles the scale-inconsistency finding; if the covariate model does not beat the raw baseline, there is no reconciliation and it is reported as such.
