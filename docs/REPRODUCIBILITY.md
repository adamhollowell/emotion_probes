# Reproducibility map

Every geometry/analysis artifact in `geometry_out/` is on the canonical basis and carries
a `_provenance` stamp pinning `vectors_sha256 = 6de2e293…` (the emotion vectors in
`data/vectors/emotion_vectors_171.pt`, also on Hugging Face). This note says, for each family,
whether a shipped script regenerates it or whether it ships as a certified output.

## Fully script-reproducible (run the producer from the repo root)

| Artifact | Producer |
